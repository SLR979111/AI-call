## 5. 技术方案书大纲（12 章）

1. 赛题理解与目标（门槛、评分维度、约束）
2. 总体架构（逻辑图 + 模块 + 依赖规则）
3. 实时语音链路（VAD/ASR/TTS/打断/AEC/双讲）
4. Agent（Flow Engine + LLM + RAG + Tools + 兜底）
5. 合规与安全（三层守卫、必说/禁语、AI 标识）
6. 数据与可观测（事件 schema、trace、回放）
7. 评测体系（开发/验证/测试、Judge、失败归因）
8. RSI 闭环（候选、回归、门槛、回滚、防过拟合）
9. 时延预算与实测（P50/P95、分解、优化杠杆、副作用）
10. 成本分析（LLM token、GPU、单次通话、限流）
11. 工程与复现（Docker、一键启动、契约测试）
12. 团队分工与贡献（RACI、跨学科协作、决策记录）

> 第 9/10 章必须有**表格与图**，不能只有文字；第 8 章必须有**基线 vs 候选**的实测对比。

## 6. 自测报告结构

```text
reports/self-test/
  00-summary.md          # 结论、关键指标、版本
  01-dataset.md          # 开发/验证/测试集说明、场景分布、噪声/对抗
  02-metrics.md          # 指标定义、公式、官方口径映射
  03-results.csv         # 每条 case 的原始结果
  04-failures.md         # 失败聚类、根因、案例
  05-rsi.md              # 基线 vs 候选、delta、CI、回滚
  06-reproduce.md        # 命令、commit、release_id、种子
  logs/                  # events.jsonl 样本（脱敏）
```

要求：

- 每个数字都能从 `logs/` + `03-results.csv` 复算。
- 标注 `release_id`、模型版本、prompt 版本、测试集版本。
- 测试集不参与调 Prompt；留出集单独封存。
- 失败案例至少 10 条，覆盖 ASR/Agent/工具/合规/时延。

## 7. 合规红线（与架构直接相关）

| 红线 | 出处 | 对设计的影响 |
|---|---|---|
| 现场严禁私自搭建外网穿透、代理 | 七(三) | **远程 3090 若靠 frp/ngrok/SSH 隧道接入，存在合规风险**；优先本地部署/公网 HTTPS，赛前书面确认 |
| 不得真实外呼、不得用真实号码/PII | 五(二)、七(一) | 全用 Mock + 合成数据；测试音频需同意与脱敏 |
| AI 生成合成内容标识 | 七(四) | 开场披露 AI 身份；UI/视频标注“AI 合成语音” |
| 必说话术/禁语 | 五(二) | 合规三层；禁语召回 100% |
| 限流与费用控制 | 七(三) | LLM 日预算、单次上限、429 熔断 |
| 开源许可证/查重 | 三(三)、五(三) | `THIRD_PARTY.md`；不用成品外呼机器人 |
| 禁止硬编码/特判 | 五(三)2 | 配置驱动；hidden set 留出；现场随机抽测 |

> 远程 GPU 这一条要单独找组委会确认：**“公网 HTTPS 访问自有服务器”是否算“外网穿透”**。在确认前，演示方案必须有一个**本地可运行**的备选。

## 9. 现场 3 分钟演示脚本

| 时间 | 动作 | 备用 |
|---|---|---|
| 0:00–0:15 | 发起外呼，开场自报身份 + AI 标识 + 录音提示 | 预置音频兜底 |
| 0:15–0:45 | 身份确认 + 需求确认 | 追问模板 |
| 0:45–1:45 | 方案/权益 + 工具查询；评委打断 | 取消 + 重调度；误打断恢复 |
| 1:45–2:30 | 结果确认 + 结构化回写 | 工具失败 → 待办/转人工 |
| 2:30–3:00 | 事件时间线 + P50/P95 + 合规命中 | 截图/录屏兜底 |

**现场规则**：评委可随时打断；准备“被打断后 3 秒内恢复”的话术；不读稿；不超时。

## 10. 答辩 7 分钟提纲

| 时间 | 内容 | 关键句 |
|---|---|---|
| 0:00–1:00 | 问题与目标 | 2s 门槛 + 闭环 + 合规，不是模型赛 |
| 1:00–2:30 | 架构与取舍 | 双状态机、合规三层、本地语音+云 LLM、Flow Pack |
| 2:30–4:00 | 时延预算与实测 | P50/P95 分解、四个杠杆、副作用 |
| 4:00–5:00 | 评测与 RSI | 基线/候选/门槛/回滚/防过拟合 |
| 5:00–5:40 | 合规与安全 | 必说/禁语/AI 标识/无真实外呼 |
| 5:40–6:30 | 团队分工 | 谁负责什么、如何集成、贡献证据 |
| 6:30–7:00 | 局限与下一步 | 诚实说未完成项 |

**高频追问备答**：为什么不全云/不全本地？为什么不用端到端语音大模型？怎么防过拟合？打断怎么做到 300ms？成本多少？失败案例？
